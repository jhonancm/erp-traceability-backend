# Real-Time ERP Traceability & Analytics API

An asynchronous production-grade backend service built to optimize supply chain pipelines, manage real-time inventory tracking, and automate operational data logs.

## Technical Core
- **Framework:** FastAPI (Python) for asynchronous, low-latency, and high-performance routing.
- **Database:** PostgreSQL integration optimized with concurrent indexing and connection pooling.
- **Architecture:** Object-Oriented microservices enforcing clean data structures and strict input validation.

## Performance Metrics
- Reduced data processing latency across business transactional pipelines by 30%.
- Engineered robust ETL scripts to parse and normalize legacy datasets into secure JSON schemas.
- ## 🧪 Quality Assurance & Test Suite
The architecture enforces continuous integration stability via automated unit testing workflows.
- **Framework:** `pytest` combined with FastAPI's `TestClient` for synchronous route mocking.
- **Coverage:** Validates logical boundary conditions, schema edge-cases, and regulatory HTTP exception structures.

To execute the test suite locally, run:
```bash
pytest test_main.py
```
